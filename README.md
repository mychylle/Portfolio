# Michelle A. Godin | Portfolio

A personal portfolio website for **Michelle A. Godin**, a fourth-year Information Technology student and UI/UX enthusiast. It introduces who I am, what I'm learning, and the projects I've built in class and on my own.

**Live site:** https://mychylle.github.io/Portfolio/

## What's on the site

- **Home:** my name, a short introduction, and the kind of work I'm learning and interested in.
- **About:** my background and interests: UI/UX design, cloud architecture, artificial intelligence, web development, and project management.
- **Skills:** the languages, frameworks, and tools I use, grouped by category.
- **Projects:** five projects, each with a screenshot, a short description, my role, the technologies used, and its current status.
- **Contact:** an email link and my GitHub profile.

## Features

- Responsive layout that works on phones and computers, with a mobile menu
- Light and dark mode with a toggle (remembers the visitor's choice)
- Navigation that highlights the section you're viewing
- Scroll-progress line and a back-to-top button
- Built with plain HTML, CSS, and JavaScript, with no frameworks or build step

## Run it locally

No installation is needed. Download or clone the repository, keep `index.html` and the `images` folder together, and open `index.html` in a browser. For a local server preview, the Live Preview extension in VS Code also works.

## Hosting

The site is published with **GitHub Pages** from the `main` branch (root folder).

To update it, edit the files, commit the changes to this repository, and wait a minute or two for GitHub Pages to republish.
